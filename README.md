# gopeed-extension-site-parser
这是一个为 Gopeed 开发的网站解析扩展。当你输入一个网站链接时，它不仅能提取当前网页中的文件，还能像爬虫一样“顺藤摸瓜”，自动深入子页面，帮你把整个网站里能下载的文件全揪出来。

🔍 核心工作流程

1. 抓取源码：获取目标网页的 HTML 源码。
2. 智能过滤：自动识别并提取源码中的 href 和 src 链接，将其转换为绝对路径并去重。
3. 精准匹配：只保留你指定后缀的文件（默认包含 html、php、png、jpg、js、css、pdf、zip 等）。

🚀 两大特色亮点

· 自动递归子页面：它不会只停留在当前页面。如果它发现页面里有其他网页链接，它会自动排队进入这些子页面继续解析，直到把深层的文件也一并挖出来。
· 域名白名单控制：为了防止爬虫跑偏（比如爬到了外部广告网站）或者卡死，你可以在扩展设置中手动配置允许解析的网站域名。只有属于白名单里的网址，它才会去深入解析。

⚙️ 安全与性能保障

为了防止网站太大导致扩展崩溃，它内置了多重保护：

· 页面上限：可以设置最大递归解析的页面数量（默认100页）。
· 文件上限：可以设置最多提取的文件数量（默认500个）。
· 静默过滤：自动跳过 javascript:、mailto: 等无效链接和页面锚点。

📦 最终输出

解析完成后，它会在 Gopeed 中为你生成一个包含所有文件的下载清单。你可以像在网盘里一样，勾选你需要的图片、文档或代码文件，一键交由 Gopeed 批量下载。
